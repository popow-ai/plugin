# Write an awareness brief from trends and memes

The user runs an account and wants its next video to be one their viewer recognizes themselves in. They have not settled which trend to follow or how to make it theirs. Finish with one shootable brief for the idea the user picked. Take only the steps the conversation still needs.

## Read what the user gave

Read these from the request and the conversation before the first step. Do not ask for one the user already gave.

| What to read | Example from one request |
|---|---|
| Account and what it is for | "Popow's official account; we want more views" |
| Viewer | "marketers and creators who make content" |
| Platform, language or region | "Reels and TikTok, English" |
| How they keep ideas | "our sheet has Reference, Target and Twist columns" |
| What they can shoot | "one person at a desk" |

The examples belong to that request; use what this user says. The viewer is enough to search for references. Ask for the viewer when it is missing; do not ask for the other four before the first step.

## Steps

1. **References:** follow finding-references. Search for recent videos that show a situation this viewer lives through, and for formats that travel between topics (a line of on-screen text, a reaction, a cut on a change in the sound) which could be moved to that situation. Skip this step when the user already brought the videos, or start from their saved videos and notes with managing-memory when they point to those.
2. **Ideas to compare:** turn the references into ideas and show them with showing-videos as a sheet, one row per idea, with the references behind it as that row's videos. One reference may give more than one idea. Use the user's own columns and order when they gave them; otherwise use reference, viewer and twist. See "Write each idea" below.
3. **The user picks:** ask which idea to shoot and wait. In the same message ask for the call to action writing-content-briefs needs, unless the user already gave one or said they want none, and for the language the video's lines and on-screen text are in when the conversation does not show it. Wanting views is the purpose of the video, not a call to action.
4. **Evidence of the reference:** when the opening and beats of the picked idea's reference are not established by what the conversation already holds, follow starting-from-a-video. A caption, a summary or comments do not establish the opening.
5. **Brief:** follow writing-content-briefs with the picked idea's reference, the viewer's situation in the twist as the one point, and what the user said they can shoot. When the user picked several ideas, write one brief for each.

Each step's skill owns its rules and questions, including what it asks before it starts. Between steps, show what you found in a few lines; continue without asking for approval except at step 3. When the user asks to keep a video with a note, follow managing-memory, then continue.

## Write each idea

- **Reference:** the video's link, and only what its returned evidence shows: the on-screen text, the action or expression, and the sound title when the result includes one. When only a caption or comments describe the video, say its scenes are unconfirmed. Add the publish date and the view count with the date it was observed.
- **Viewer:** the person and the moment, such as "a brand marketer waiting for approval on a plan". An audience name alone ("marketers") is not a moment.
- **Twist:** what stays from the reference and what changes for this account. Say which it is: shot as the reference is, the same format moved to the viewer's situation, or one prop or setting changed. A twist is a proposal; never write it as something the reference shows.
- **Why this reference:** what in the video or its comments shows that viewers relate to it. A comment about the same experience supports this; a high view count alone does not.

Views compare references with each other: similar videos posted around the same time, each with its observation date. They do not forecast how the user's video will perform, and you do not rank ideas by a predicted result. When references are too few or too far apart in time to compare, say so.

## Sound

A sound title is something a result returned for one video. Popow has no search by sound: it cannot list other videos that use the same sound, and a keyword search for the sound's title is a different search that returns videos mentioning those words. When the user asks for videos with the same sound, answer in a line or two: Popow cannot search by sound, and you will compare such videos once they bring the links. Finding them is the user's own step, so do not run a Popow search in its place; go on with the rest of the request. Never present keyword results as videos that use the sound.

In the brief, name a sound and the moment an expression or cut changes with it only when the reference's evidence establishes them. Otherwise leave the sound for the user to choose and say it was not confirmed.

## Finish

The work is finished when the brief for the picked idea is delivered. Filling in the user's own sheet, filming, posting and reviewing how the video performed are the user's next steps, not steps of this skill.

After the brief skill's output, add a few lines, never as new brief fields:

- **From the reference:** the beats, text or timing that follow what was confirmed in the reference, with its link.
- **New for this video:** the lines, actions and scenes you proposed.
- **Unconfirmed:** any reference beat, sound or timing you could not establish.

## Anti-Patterns

- Choosing the idea for the user, or writing a brief before they picked.
- Presenting a proposed scene, line or twist as something the reference shows.
- Ranking ideas by expected views, or promising reach.
- Using a keyword search in place of a search by sound.
- Stopping at a list of references or ideas when the user asked for something to shoot.
